Voidwire 1.0.0 is the first stable release: send links, text and files between your own devices, end to end encrypted, with no account.

## Everywhere
- Pair any two devices (PC and phone, PC and PC, phone and phone) with a QR code or a short `VW-…` code, confirmed with a 6-digit code on both screens.
- Direct connection on your local network first; otherwise an encrypted relay that can't read what you send. Use the public relay or run your own (Docker or plain binaries, see `docs/self-host-relay.md`); each pairing can use a different relay.
- No account, no phone number, no telemetry. Optional history and diagnostics are off by default.
- Signed in-app updates on Windows, Android and the Linux AppImage. The apps reject any update that isn't signed with a pinned key.

## Windows 10/11 (x64)
- Tray app with **Send with Voidwire** in Explorer's right-click menu. Sends links, clipboard text and files, and receives them (files after you accept).
- The installer isn't code-signed, so SmartScreen may warn. Check `SHA256SUMS` first.

## Android 8.0+
- Share from any app's share sheet, scan pairing codes, receive links, text and files.
- Not on Google Play or F-Droid: install the APK directly.

## Linux (beta), x86_64
- The same tray app as on Windows, as a `.deb` (Ubuntu 22.04+, Debian 12+) or an AppImage, with **Send with Voidwire** in Nautilus, Dolphin and Nemo.
- Beta: Linux has had less testing than Windows and Android. Please report problems in Issues. The `.deb` doesn't update itself; the update check opens the release page.

## Browser extension (Chrome, Edge, Brave, Firefox)
- Send the current tab, a link, selected text or your clipboard. It talks only to the Voidwire app on the same PC. Not in the extension stores yet: load it unpacked (Chromium) or as a temporary add-on (Firefox).

## Not yet
- No macOS or iOS app yet.

## Security
- Voidwire has not been independently audited. The protocol, threat model and their known weak points are documented in the repository.
- Report vulnerabilities privately as described in [SECURITY.md](https://github.com/voidwire-app/voidwire/blob/master/SECURITY.md), not in a public issue.

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or `Get-FileHash` (Windows).
