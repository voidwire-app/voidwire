Voidwire 1.1.0-m5.3 is a test build (pre-release) with fixes from hands-on Linux testing and a new default shortcut. It is offered only to installs on the test channel (Settings → Updates → Test builds). Linux and macOS are still in beta.

## All desktops
- New default send-clipboard shortcut: **Ctrl+Shift+Alt+V** (macOS: Control+Shift+Option+V). Ctrl+Shift+V clashed with paste in terminals. If you picked your own keys, you keep them.
- **Start Voidwire when I sign in** (Settings): off until you turn it on. Voidwire then starts in the tray with no window.
- The tray menu has **Open Voidwire**.
- The Pair window opens centered over Voidwire's window, or in the middle of the screen.
- Switching **Test builds** checks for updates once, right away.
- The browser extension from Microsoft Edge Add-ons can talk to the desktop app.

## Linux (beta)
- GNOME without app shortcuts (for example Ubuntu 24.04): Settings has **Add shortcut in GNOME settings**, which adds the shortcut to GNOME's keyboard settings without touching your other shortcuts. **Remove** takes it out again.

## Android
- Switching **Test builds** checks for updates once, right away.

## Browser extension
- Firefox needs version 140 or later. The extension lists what it sends to the desktop app (the page address, a link or selected text, only when you click).

## Security
- Voidwire has not been independently audited. Report vulnerabilities privately as described in [SECURITY.md](https://github.com/voidwire-app/voidwire/blob/master/SECURITY.md), not in a public issue.

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing` (Linux, macOS: `shasum -a 256 -c`) or `Get-FileHash` (Windows).
