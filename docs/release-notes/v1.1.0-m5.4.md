Voidwire 1.1.0-m5.4 is a test build (pre-release) with fixes from a second round of hands-on Linux testing. It is offered only to installs on the test channel (Settings → Updates → Test builds). Linux and macOS are still in beta.

## Linux (beta)
- KDE Plasma 5.27 to 6.4: the send-clipboard shortcut works. These versions can't bind app shortcuts, so Settings has **Add shortcut in KDE settings**, which adds it to System Settings › Shortcuts. If the keys are taken or KDE refuses, Settings says why. System Settings opens only when you click **Open shortcut settings**.
- Wayland: the shortcut and the tray's **Open Voidwire** bring a Voidwire window that is behind others to the front, and the device picker opens in front instead of as a "Voidwire is ready" notification.
- AppImage: after an update, `Voidwire_<version>_amd64.AppImage` takes the new version's name (a name you chose is kept). Start at sign-in and the shortcut follow it.
- GNOME opens windows without a parent (Voidwire's main window, Settings) where it likes. To have it center new windows: `gsettings set org.gnome.mutter center-new-windows true`. The Pair window still centers over Voidwire's window.

## Security
- Voidwire has not been independently audited. Report vulnerabilities privately as described in [SECURITY.md](https://github.com/voidwire-app/voidwire/blob/master/SECURITY.md), not in a public issue.

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing` (Linux, macOS: `shasum -a 256 -c`) or `Get-FileHash` (Windows).
