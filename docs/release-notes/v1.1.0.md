Voidwire 1.1.0 takes the Linux app out of beta and adds a few things on every desktop.

## Linux is out of beta
- The Linux app (.deb and AppImage) has had a full round of hands-on testing on GNOME and KDE Plasma and is no longer marked beta.
- GNOME and KDE: where the desktop doesn't let apps set keys, Settings has **Add shortcut** and **Remove** buttons that put the send-clipboard shortcut into your desktop's own keyboard settings, plus a button that opens those settings.
- AppImage: from this version on, an in-app update also puts the new version number in the file name (the update to 1.1.0 itself keeps the old name). If you renamed the file yourself, your name is kept.

## New on desktop
- **Start Voidwire when I sign in**: a new setting (off until you turn it on). Voidwire starts in the tray without opening a window.
- The send-clipboard shortcut is now **Ctrl+Shift+Alt+V** by default, so it no longer clashes with "paste as plain text". If you picked your own keys, they stay.
- **Sends to**: choose which device the shortcut sends to, and it goes straight there with no question. With only one paired device it goes to that one. If you unpair the chosen device, it goes back to asking.

## Browser extension
- The extension is now on [Microsoft Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/gdcjokipaeghnjfcbnjeofbealnkdgbh). Chrome, Brave and Firefox still load it from the download.

## Not yet
- macOS is coming soon. No iOS app.

## Security
- Voidwire has not been independently audited. Report vulnerabilities privately as described in [SECURITY.md](https://github.com/voidwire-app/voidwire/blob/master/SECURITY.md), not in a public issue.

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or `Get-FileHash` (Windows).
