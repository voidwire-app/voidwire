Voidwire 1.0.1 fixes problems found in hands-on testing of the Linux app. Linux is still in beta. Windows, Android and the browser extension get the same version number but no changes you'll notice.

## Linux (beta) fixes
- AppImage: after an in-app update, **Restart now** opens Voidwire again. Before, the new version didn't start.
- AppImage: an update no longer leaves the old image mounted, and links you open no longer pick up the AppImage's own libraries and theme.
- KDE Plasma (Wayland): the send-clipboard shortcut no longer sends old clipboard text. If Voidwire can't read the current clipboard, it sends nothing.
- Files (Nautilus): right-click **Send with Voidwire** works again. Before, it failed for every file.
- A send that fails while the Voidwire window is hidden (from the tray or the file manager) now shows its error instead of failing silently.
- GNOME: the send-clipboard shortcut is shown as Ctrl+Shift+V instead of `<Shift><Control>v`.

## Not yet
- No macOS or iOS app yet.

## Security
- Voidwire has not been independently audited. Report vulnerabilities privately as described in [SECURITY.md](https://github.com/voidwire-app/voidwire/blob/master/SECURITY.md), not in a public issue.

Verify downloads with `sha256sum -c SHA256SUMS --ignore-missing` (Linux) or `Get-FileHash` (Windows).
