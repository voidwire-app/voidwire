## macOS (beta), new
- A universal app for Apple silicon and Intel Macs, macOS 13 Ventura or later: `Voidwire_<version>_universal.dmg`. It lives in the menu bar (no Dock icon) and works with the browser extension.
- Beta: macOS has had less testing than Windows and Android. Please report problems in Issues.
- Not notarized by Apple. The first time you open it, allow it in **System Settings › Privacy & Security › Open Anyway** (steps in the README). Run it from Applications so the browser extension can find it.
- The update check tells you about new versions and opens the release page; it doesn't install them itself. No desktop notifications.
