# Dependency license inventory (M0, updated for M1)

*Generated Oct 9, 2026 from the M0 tree. Rust: `cargo deny check licenses` (policy in `/deny.toml`, all targets: Linux, Windows MSVC, macOS x64/arm64, Android arm64/armv7/x86_64) plus `cargo metadata` for the exact expressions. Android: `./gradlew generateLicenseReport` (jk1 dependency-license-report, `releaseRuntimeClasspath`; output in `android/app/build/reports/dependency-license/`). ## Our own code
All first-party crates (`voidwire-core`, `voidwire-desktop`, `voidwire-push-gw`, `uniffi-bindgen` wrapper) declare `license-file = "LICENSE"` (via `license-file.workspace = true`), not an SPDX id. `LICENSE` is a CC0 1.0 Universal waiver with an MIT License fallback. It ships in every artifact together with a generated `THIRD-PARTY-LICENSES.txt` (D8):

| Artifact | LICENSE | THIRD-PARTY-LICENSES.txt |
|---|---|---|
| `.deb` | `/usr/share/doc/<package>/copyright` and `/usr/lib/<product>/LICENSE` | `/usr/share/doc/<package>/THIRD-PARTY-LICENSES.txt` and `/usr/lib/<product>/` |
| AppImage | `usr/lib/<product>/LICENSE` | `usr/lib/<product>/THIRD-PARTY-LICENSES.txt` |
| NSIS installer | shown on the license page (`bundle.licenseFile`) and installed as `$INSTDIR\LICENSE` | `$INSTDIR\THIRD-PARTY-LICENSES.txt` |
| APK | `assets/LICENSE` | `assets/THIRD-PARTY-LICENSES.txt` |

Generated by `scripts/gen-third-party.py` (cargo-about with `about.toml` for the Rust crates in that artifact's targets; for the APK also the Gradle report) and wired in by `scripts/tauri-dist-config.py` (desktop) and `android/app/build.gradle.kts` (missing file = build failure). Crates whose package has no license file get the SPDX text plus their declared authors and any COPYING/NOTICE file; `curve25519-dalek` is clarified in `about.toml` so its real copyright lines are used.

## Enforcement
- Rust: `cargo deny check licenses` (CI `deny` job), allow-list in `deny.toml`.
- Android (D12): `scripts/check-android-licenses.py` runs inside `scripts/build-android.sh` (so in CI's android job and the pre-release) and fails on any runtime module whose POM license isn't allow-listed (Apache-2.0, MIT, BSD-2/3, ISC), on a missing/empty report, and on any change to the JNA exception's declared license.
